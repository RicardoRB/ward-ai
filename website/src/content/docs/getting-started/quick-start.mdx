---
title: Quick start
description: Configure and run your first Ward check.
---

From a supported Maven, Gradle, TypeScript, or JavaScript project, detect the project, create a
configuration, and run the gates:

```bash
ward detect
ward init
ward check
```

`init` starts an interactive wizard. To have your coding agent guide the setup and tune the rules to
your code, install the [agent skills](/integrations/agent-skills/) and ask it to set up Ward.

For non-interactive setup, choose a preset or explicit gates:

Gradle projects use `build.gradle` or `build.gradle.kts`; Ward prefers `./gradlew` and falls back
to `gradle` when no wrapper is available.

TypeScript and JavaScript projects use the package manager their `packageManager` field or lock file
names (npm, pnpm, Yarn, or Bun). `init` adds the tools it needs as dev dependencies, runs the
install, and writes the tools' config files:

```bash
cd my-app
ward detect   # Language: TypeScript, Build tool: pnpm, Framework: Vue, Node: 22
ward init --preset strict --integration none
ward check
```

```bash
ward init --preset standard --integration none
ward init --preset strict --integration claude-code
ward init --integration none --gate tests
```

A passing run ends with a summary such as:

```text
Quality Gate: PASSED
7 passed · 0 failed · 0 skipped
```

Use `ward check --format json` for automation. The JSON contract guarantees that stdout contains
only JSON; diagnostics go to stderr. If something does not work, run
[`ward doctor`](/commands/doctor/). See [commands](/commands/check/),
[exit codes](/reference/exit-codes/), and [CI/CD](/guides/ci-cd/).
