exported-service	default	Lint reports only the component with android:exported="true"; Ward also reports one that has an intent filter and no exported attribute, which is exported before Android 12 and a build error from it.
exported-receiver	default	Lint reports only the component with android:exported="true"; Ward also reports one that has an intent filter and no exported attribute, which is exported before Android 12 and a build error from it.
exported-content-provider	default	Lint also reports a provider with no exported attribute, whose default was exported before API 17; Ward follows the default of API 17 and later (not exported). Lint reports the element, Ward the exported attribute.
